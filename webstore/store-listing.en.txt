■ Name
Petarin

■ Summary (max 132 chars)
Sticky notes in profiles like Work or Personal. Cling to any page's edge, tuck away until needed. Local by default, optional sync.

■ Description (max 16,000 chars)
Petarin lets you stick notes to the edge of any web page. Notes live in profiles you create — "Work", "Personal", and so on — and the profile you pick shows up on every site. They cling to the edge of the screen and stay neatly tucked away so they never get in the way — open them only when you need them.

■ Features

🔹 Profiles, not sites
Create profiles such as "Work" and "Personal" and switch between them. The profile you pick shows on every site, so you never have to re-stick a note just because you changed tabs.

🔹 Notes that cling to the edge
Notes magnetically stick to the screen edge (right, left, top, or bottom). Drag the spine to slide a note along the edge — the cross axis is locked so things never get messy.

🔹 Small by default, full size when opened
While collapsed, a note shows just its emoji icon or the first few characters. Click the spine to expand and write (up to 2 lines). Pick from 7 colors and an emoji icon.

🔹 Collapse them all at once
Opened a lot of notes? Click outside the page, press Esc, or use the "collapse all" button to tuck them all away in one go.

🔹 See everything from the popup and manager
Switch the active profile from the toolbar icon, and browse every saved note across all profiles in the Notes Desk. Create, rename, reorder, and delete profiles there too. Choose the placement (right/left/top/bottom), toggle translucency, and turn the on-page rail on or off.

🔹 Privacy first — zero external transmission by default
By default, notes and settings are stored entirely in the browser's local storage (storage.local) and are never sent to any server operated by the developer. No account required.

🔹 Multi-PC sync (optional, off by default)
Only if you turn it on yourself in the manager (Notes Desk), the notes for the profiles you choose are synced across your devices through the browser's built-in sync storage (storage.sync) — that is, via your browser's own sync service (Google / Microsoft / Mozilla, whichever you are signed into). It is off by default, and while off there is zero external transmission. Sync works only within the same browser family (Chrome, Edge, and Firefox are separate silos).

■ Permission justification

  storage:
  To save the notes (text, color, icon, placement) and user settings (placement, translucency, on-page toggle) in on-device storage (chrome.storage.local). Nothing is sent to any server operated by the developer. Only if the user turns on optional multi-PC sync, the notes for the selected profiles are synced across the user's devices through the browser's built-in sync storage (chrome.storage.sync); off by default.

■ Host permission justification

  http://*/* and https://*/*:
  To draw the sticky-note rail (content script) at the edge of every http(s) page so notes can be stuck on each page. The rail is rendered in an isolated Shadow DOM only; it never reads or modifies the page DOM (no interference with the page's own content) and performs no external transmission. Note data is stored in on-device chrome.storage.local (and, if the user turns on optional multi-PC sync, via chrome.storage.sync through the browser's sync service).

■ Are you using remote code?
No
(All code is contained within the extension package; no code is loaded from external sources.)
