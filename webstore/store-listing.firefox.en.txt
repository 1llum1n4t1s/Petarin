■ Name
Petarin

■ Summary (max 250 chars)
Sticky notes for web pages, organized into profiles like Work and Personal. They cling to the screen edge and tuck away until needed. Open to jot a memo with colors and emoji. Switch profiles from the popup. Local by default, optional multi-PC sync.

■ Description (max 16,000 chars)
Petarin lets you stick notes to the edge of any web page. Notes live in profiles you create — "Work", "Personal", and so on — and the profile you pick shows up on every site. They cling to the edge of the screen and stay neatly tucked away so they never get in the way — open them only when you need them.

■ Features

🔹 Profiles, not sites
Create profiles such as "Work" and "Personal" and switch between them. The profile you pick shows on every site, so you never have to re-stick a note just because you changed tabs.

🔹 Notes that cling to the edge
Notes magnetically stick to the screen edge (right, left, top, or bottom). Drag the spine to slide a note along the edge — the cross axis is locked so things never get messy.

🔹 Small by default, full size when opened
While collapsed, a note shows just its emoji icon or the first few characters. Click the spine to expand and write (up to 2 lines). Pick from 7 colors and an emoji icon.

🔹 Collapse them all at once
Opened a lot of notes? Click outside the page, press Esc, or use the "collapse all" button to tuck them all away in one go.

🔹 See everything from the popup and manager
Switch the active profile from the toolbar icon, and browse every saved note across all profiles in the Notes Desk. Create, rename, reorder, and delete profiles there too. Choose the placement (right/left/top/bottom), toggle translucency, and turn the on-page rail on or off.

🔹 Privacy first — zero external transmission by default
By default, notes and settings are stored entirely in the browser's local storage (storage.local) and are never sent to any server operated by the developer. No account required.

🔹 Multi-PC sync (optional, off by default)
Only if you turn it on yourself in the manager, the notes for the profiles you choose are synced across your devices through the browser's built-in sync storage (storage.sync) — on Firefox, via your Mozilla account sync. It is off by default, and while off there is zero external transmission. Sync works only within the same browser family.

■ Permissions
- storage … to save notes and settings locally (and, only if you turn on optional multi-PC sync, via storage.sync through the browser's sync service)
- alarms … only while Cloud Sync is on, to periodically re-establish the connection to the relay
By default no network requests are made (only when you turn on multi-PC sync are the selected profiles' notes synced via the browser's sync service).
