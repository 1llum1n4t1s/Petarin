Features

思いついたその場に、貼っておける。

付箋は画面の端に吸い付いて、ふだんは小さく格納。開けばそのままメモできます。

🗂️

プロファイルで使い分け

「仕事用」「個人用」など用途ごとの束を作り、いま使うものを選ぶだけ。選んだ束の付箋が、どの画面でもそのまま出てきます。

作成・改名並べ替えいくつでも
📌

端に吸い付く付箋

右・左・上・下の好きな端に磁石のように貼り付きます。背をドラッグすれば端に沿って移動でき、軸はロックされるので散らかりません。

📝

Markdown で書ける

編集中は Markdown のまま、閉じると見出し・箇条書き・太字・表・リンクを整形して表示します。長文もスクロールできる普通の付箋です。

見出し表リンク
🎨

色と絵文字で見分ける

9 色のパレットと絵文字アイコン。畳んでいるときはアイコンだけが小さく見えるので、目的の付箋をすぐ選べます。

✍️

書体も大きさも自分好みに

ゴシック・等幅・手書き風など 12 書体を同梱。文字サイズや編集時の行番号表示も切り替えられます。

🔒

既定で外部送信ゼロ

付箋も設定も、既定では端末の中だけに保存されます。アカウント登録は不要で、広告も解析も入っていません。

⇄

端末間で同期（任意）

オンにしたときだけ、複数の端末で付箋を共有できます。本文もプロファイル名も端末側で暗号化してから送るので、中継サーバーからは読めません。

E2E 暗号化QR ペアリング
🗑️

消しても戻せる

剥がした付箋はゴミ箱へ。最新 100 件までは「付箋デスク」からいつでも元の場所に戻せます。

🔄

いつでも最新版に

Windows 版は署名済みインストーラーで配布し、更新は自動で届きます。ブラウザ拡張はストア経由で更新されます。
